# Клёвый прогноз (FishCast)

**Клёвый прогноз (FishCast)** — веб-приложение (PWA) и мобильное Android-приложение (Capacitor) для рыболовов: интерактивная гидрографическая карта водоёмов, многофакторный прогноз клёва (**F-Индекс**), батиметрия и импорт логов эхолота, верифицируемая сообществом база ихтиофауны, региональный поиск крупных водохранилищ, справочник видов рыб и рыболовных узлов, дневник уловов и маршруты до берега.

---

## Основные возможности

### 1. Интерактивная карта водоёмов и GPS-автопоиск
- **Автоопределение геопозиции (GPS)** в мобильном приложении и мобильном браузере: при запуске приложение определяет текущую точку пользователя, обновляет погоду и автоматически находит ближайшие водоёмы из OpenStreetMap вокруг него.
- **Слои карты**: схема OSM, спутниковые снимки, OpenSeaMap (навигационная батиметрия), топографическая подложка, тепловая карта свежих отчётов, изобаты глубин, перспективные бровки/ямы и наложение исторических карт русла до затопления (PNG/JPG/WebP с регулируемой прозрачностью).
- **Офлайн-области карты**: выделение произвольного прямоугольника на карте и кэширование плиток, водоёмов, глубин и прогнозов в **IndexedDB**.

### 2. Многофакторный прогноз клёва (`F-Индекс` 0–100)
- **Почасовой график на 24 часа и 3 дня** (`Recharts`) с выделением пика активности и разбором каждого фактора.
- Учитываются:
  - **Барометрическая динамика** за 6 и 48 часов (резкие скачки давления, предфронтовое падение, антициклональная стабильность).
  - **Термическая инерция воды** по 7- и 14-дневной истории температур воздуха `Open-Meteo` с учётом глубины водоёма и автоматическим переключением в подлёдный режим (первый лёд / глухозимье / последний лёд).
  - **Речной сток и паводок** (`Open-Meteo Flood API` + осадки за 72 ч — оценка мутности воды).
  - **Биофазы и астрономия**: восход/закат по широте, сумеречные пики, фаза луны, солнечная радиация, наветренный берег, риск дефицита кислорода.
  - **Байесовская калибровка** прогноза на реальных отчётах уловов и отметок «Клёва не было».
- **Виджет «Хороший клёв»** на карте: рейтинг лучших водоёмов (`F ≥ 66`) с фильтром по виду рыбы, дню («Сегодня» / «Завтра»), региону и масштабу водоёма.

### 3. Верифицируемая база ихтиофауны (`verified_species`)
- Для каждого водоёма рассчитывается реалистичный состав рыбы на основе его типа, площади, максимальной глубины, проточности и кураторского каталога (исключены нереалистичные комбинации вроде судака или жереха в мелком ручье или деревенском пруду).
- **Механизм верификации сообществом**:
  - В карточке каждого водоёма рыбаки могут в один клик подтвердить вид (**«Водится»**) или отметить ошибку базы (**«Нет здесь»**), а также через форму **«Уточнить»** добавить недостающий вид с оценкой встречаемости (`основная` / `обычная` / `редко`) и комментарием.
  - Реальные отчёты об уловах автоматически подтверждают вид в `verified_species`.
  - Виды, отмеченные сообществом как отсутствующие, исключаются из списка обитающих и из рейтинга «Хорошего клёва» (с возможностью восстановления в один клик).
  - Голоса дедуплицируются по пользователю / анонимному отпечатку и защищены серверным rate-limit.

### 4. Региональный фильтр и отбор крупных водоёмов
- Поддержка **14 рыболовных регионов** (Московская, Тверская, Ярославская, Смоленская, Калужская, Рязанская, Владимирская, Тульская, Курская, Нижегородская, Самарская, Астраханская, Ленинградская области и Республика Карелия).
- Переключатель **«Только крупные водоёмы»** отсеивает мелкие притоки, ручьи и дачные пруды, оставляя в анализе и поиске **OSM** крупные водохранилища (Истринское, Можайское, Рузское, Озернинское, Пестовское, Учинское, Пироговское, Клязьминское, Иваньковское, Рыбинское и др.), большие озёра и магистральные реки/каналы.
- Интеграция с **OpenStreetMap (Photon + Overpass + Nominatim GeoJSON)** корректно извлекает мультиполигоны водохранилищ с островами и протяжённые каналы/реки.

### 5. Батиметрия, эхолот и разведка водоёма
- **Автопостроение изобат** и **профиля дна** (`Recharts AreaChart`) вдоль главной оси промеров, линий Запад → Восток и Юг → Север.
- **Импорт логов эхолота** (`CSV`, `TXT`, `GPX` — Deeper, Lowrance, Garmin, Praktik) до 400 точек за загрузку + ручное добавление точек промера с карты.
- **Автоопределение перспективных точек**: русловые бровки, свалы и зимовальные ямы.
- **Асинхронная разведка водоёма**: оценка кормовой базы, кислородного режима и индекса перспективности.

### 6. Маршруты до берега, справочник и дневник уловов
- **Мультимодальная навигация до точки лова**: автомобильный маршрут до проверенного съезда (OpenRouteService / Valhalla FOSSGIS / OSRM с опцией избегать грунтовых дорог) + пеший участок от парковки до берега.
- **Справочник рыб, приманок и узлов**: подбор приманок под текущий сезон, прозрачность и глубину; пошаговые схемы рыболовных узлов с полным офлайн-кэшированием в `IndexedDB`.
- **Дневник уловов и лента «Клюёт сейчас»**: WebSocket-обновление в реальном времени, учёт погодного вектора в момент поклёвки, фото улова (с опциональным распознаванием вида на сервере), приватность записей и офлайн-очередь синхронизации (`sync_queue`).
- **PWA Push-уведомления**: автоматические оповещения о росте F-Индекса выше заданного порога на избранных и ближайших водоёмах.

## Архитектура и стек технологий

| Слой | Технологии |
|---|---|
| **Frontend** | React 19, TypeScript, Vite 6, Tailwind CSS 4, MapLibre GL JS, Recharts, Lucide React |
| **Backend** | Node.js, Express 4, WebSocket (`ws`), Zod, bcryptjs, JSON-хранилище с персистентностью (`data/fishcast-db.json`) |
| **Офлайн и PWA** | `vite-plugin-pwa`, Workbox Service Worker, `IndexedDB` (`offlineDb.ts`) |
| **Мобильное приложение** | Capacitor 8 (Android WebView, оригинальные адаптивные иконки `mipmap-*`, GPS-разрешения `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION`, автономный режим без бэкенда) |
| **Внешние гео/метео API** | Open-Meteo Forecast & Flood API, OpenStreetMap (Photon, Nominatim, Overpass), OpenSeaMap, Valhalla / OSRM / OpenRouteService |

## Основные API-эндпоинты

| Метод и путь | Назначение |
|---|---|
| `GET /api/v1/water-bodies` | Список водоёмов с фильтрами `bbox`, `lat/lng/radius`, `region_id`, `major_only`, `include_unnamed` |
| `GET /api/v1/water-bodies/nearby` | Ближайшие водоёмы с расчётом расстояний и подъезда (`region_id`, `major_only`) |
| `POST /api/v1/water-bodies/discover` | Поиск и загрузка водоёмов из OSM (Photon + Overpass + Nominatim) с учётом `region_id` и `major_only` |
| `POST /api/v1/water-bodies/:id/species-verification` | Верификация вида рыбы (`confirm` / `absent`, `abundance`, `note`) с дедупликацией голосов |
| `GET /api/v1/water-bodies/:id/bathymetry/tiles` | Изобаты и точки промеров глубин водоёма |
| `POST /api/v1/water-bodies/:id/depth-points/import` | Массовый импорт промеров эхолота (CSV/GPX, до 400 точек) |
| `GET /api/v1/forecast` | Прогноз клёва (`F-Индекс`) на 3 дня с факторами и калибровкой |
| `GET /api/v1/forecast/good-bite` | Рейтинг водоёмов с хорошим клёвом (`F ≥ 66`, поддержка `region_id` и `major_only`) |
| `GET /api/v1/weather` | Погода + 14-дневная история температур + сток рек (`Open-Meteo`) |
| `POST /api/v1/route-multi` | Мультимодальный маршрут (авто до съезда + пешком до берега) |
| `GET / POST /api/v1/reports` | Лента и публикация отчётов уловов (автоматически подтверждают вид в `verified_species`) |
| `GET /api/v1/species`, `GET /api/v1/knots` | Справочник видов рыб и рыболовных узлов |
| `WS /ws` | Канал реального времени (`reports:new`, `depth:new`, `species:verified`) |

## Локальный запуск и разработка

### Требования
- **Node.js 20+** и **npm**

### Установка и запуск

```bash
npm install
npm run dev
```

Приложение и API запускаются на `http://localhost:3000`.

### Переменные окружения (`.env`, опционально)
Все ключевые функции (карта, погода Open-Meteo, поиск OSM, маршруты Valhalla/OSRM, прогноз F-Индекса) работают **без платных ключей**. При желании можно указать в `.env` (см. `.env.example`):
- `PORT` — порт сервера (по умолчанию `3000`);
- `SESSION_SECRET` — секрет подписи cookie-сессий;
- `ORS_API_KEY` — ключ OpenRouteService (приоритетная маршрутизация);
- `ACTIGATOR_API_KEY` — внешний источник прогноза клёва;
- `GEMINI_API_KEY` — серверное распознавание вида рыбы по фотографии;
- `VITE_API_BASE_URL` — URL удалённого API при сборке автономного Android APK.

### Тестирование, линтинг и продакшн-сборка

```bash
npm test          # Модульные тесты модели клёва, верификации, регионов и геометрии
npm run lint      # Проверка типов TypeScript (tsc --noEmit)
npm run build     # Сборка клиента и PWA в dist/
npm start         # Запуск production-сервера
```

## Сборка Android APK (Capacitor)

### Локальная сборка
```bash
npm run build
npx cap sync android
cd android && ./gradlew assembleDebug
```
Готовый файл появится по пути `android/app/build/outputs/apk/debug/app-debug.apk`.

### Автоматическая сборка через GitHub Actions
Workflow `.github/workflows/android-apk-release.yml`:
1. Запускается при `push` в ветку `main`/`master`, при создании тега `v*` или вручную (**Actions → Build & Release Android APK → Run workflow**).
2. Прогоняет unit-тесты и проверку типов TypeScript, собирает веб-бандл `dist/`, синхронизирует Capacitor и компилирует APK в Gradle.
3. Публикует `FishCast-debug-installable.apk` в **GitHub Releases** и Artifacts.
   - При наличии секретов подписи (`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`) дополнительно собирается подписанный `FishCast-release-signed.apk`.
   - При заданной переменной `VITE_API_BASE_URL` мобильное приложение синхронизируется с удалённым сервером; без неё APK работает полностью автономно на встроенной базе водоёмов, прямых запросах `Open-Meteo` и `Photon OSM`, и локальном `IndexedDB`.

## Отказ от ответственности
Прогноз клёва (`F-Индекс`) носит вероятностный характер и не гарантирует улов. Карты глубин и изобаты предназначены исключительно для любительской рыбалки и **не должны использоваться для судовождения и навигации**. Соблюдайте региональные правила рыболовства и сроки нерестового запрета.
